# 项目架构

Python 应用位于 `src/`，由同一个 `agent-base` 项目安装，并在同一进程中运行。`agent/` 是 Agent 核心，`app/` 提供 HTTP 接口和应用服务；依赖方向为 `app → agent`。

```text
agent-base/
├── src/
│   ├── agent/
│   │   ├── agents/          # Agent 组装
│   │   ├── capabilities/    # 专业能力
│   │   ├── context/         # 上下文
│   │   ├── models/          # 模型配置和路由
│   │   ├── orchestration/   # 编排
│   │   ├── prompts/         # Prompt 配置与渲染
│   │   └── skills/          # 技能加载与选择
│   └── app/
│       ├── api/             # HTTP 路由与 SSE 序列化
│       ├── schemas/         # HTTP 请求和响应模型
│       ├── services/        # 会话、Agent 运行及应用事件
│       ├── config/          # 运行配置与 .env 加载
│       ├── main.py          # FastAPI 入口
│       └── logging.py       # 日志配置
├── eval/                    # Agent 行为评测
├── test/                    # 软件测试
├── scripts/                 # 辅助脚本
└── pyproject.toml
```

HTTP 请求由 `app.api` 校验并交给 `app.services`。服务层负责会话、运行和事件，调用 `agent.agents`、`agent.models`、`agent.prompts` 等核心模块。HTTP 数据模型留在 `app.schemas`；服务层的流事件定义在 `app.services.events`，由 API 层转换为 SSE。Agent 核心不依赖 `app` 或 FastAPI。

`eval/` 与 `test/` 保留在两个应用包外。`eval/` 用于 Agent 行为评测，`test/` 用于软件功能验证。尚未实现的规划目录不预先建立。

从仓库根目录执行 `uv sync` 安装项目，再运行 `uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`。应用在启动时工作目录读取 `.env`，相对会话数据库路径也以该目录为基准。
